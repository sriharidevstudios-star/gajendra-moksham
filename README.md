# Gajendra Moksham — గజేంద్ర మోక్షం — गजेन्द्र मोक्ष

**Working series:** Gajendra Moksham: The Elephant King's Deliverance.  
**Owner:** Sri Hari Dev Studio · **Languages:** Telugu first, then Hindi and English.

This repo is a **new, plan-only foundation**, modeled on the existing `sriharidevstudios-star/prahlada-narasimha` production architecture. The proposed first season has six connected ~6-minute episodes adapting **Śrīmad Bhāgavatam, Canto 8, Chapters 2–4**. Six is an editorial starting point, not a locked runtime or completed script.

## Scope reality

**Present:** source-grounded planning, continuity/style directions, provisional season index, unapproved character design briefs, an empty asset registry, no-voice-selected casting state, and handoff docs.

**Not yet present:** written `episode.json` scene/dialogue sources, full Telugu/Hindi/English scripts, recording or TTS manifests, references, keyframes, audio, motion, lip-sync, publishing masters, a running production pipeline, or validation scripts. Planned paths in `season.json` do **not** prove files exist. No media or model generation was performed in this batch.

## Development workflow

Work directly through GitHub on `production-artwork` with a draft PR to `main`. One bounded batch per chat; make source-grounded changes only; record missing outputs truthfully; commit without force and verify the remote head. Never transfer Prahlada-specific lore, dialogue, asset hashes, or approved-image claims.
